# Adding an evaluator

Classify every measure as universal, template-specific, scenario-specific, or reference-derived. Universal measures may score discoverability, deterministic setup, isolation, test routing, evidence quality, and successful execution. Framework or architecture conventions belong to templates and must not lower an unrelated repository's universal score.

Prefer behavioral checks over text markers. When structure is contractual, explain why the path or owner matters. Version prompts, guidance, baselines, checks, weights, and templates; never compare incompatible versions as one experiment.

Evaluator output must be structured JSON with evidence for every result. A recommendation must point to observed evidence and distinguish missing documentation from agent failure or environment failure.
